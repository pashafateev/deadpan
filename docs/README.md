# Docs

Planning notes for deadpan. Start with the decisions.

- [decisions.md](decisions.md): what's settled and what's deferred.
- [scope.md](scope.md): how big the project is, the hard parts, the stages, and
  what's out of scope.
- [architecture.md](architecture.md): how the pieces fit and how a hand flows.
  Partly proposed rather than confirmed; it says which parts.
- [options-considered.md](options-considered.md): alternatives for drawing the
  table, platforms, rules libraries, the server and styling, and why each was
  or wasn't picked.
- [design-brief.md](design-brief.md): the brief given to Claude Design for the
  mockups.

When a decision changes, update `decisions.md` first, then any doc that
describes the old choice.
